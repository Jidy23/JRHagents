# V22 — from multiple runtimes to a single skill

This is an intentional product simplification requested by the project owner.

- **Main artifact**: `skills/jrhagents/SKILL.md` (one canonical skill).
- **Support**: topic references, templates and optional read-only project scan.
- **Non-native AI**: `UNIVERSAL_PROMPT.md` fallback.
- **Website**: installation documentation only, **not** an AI app or demo of live integrations.
- **Removed from main**: old Python CLI/MCP server, plugin manifests, sample fake integrations, downloadable wheels, mock execution UI, obsolete tests and workflows. Source is still in Git history before this release.
- **Safety**: no files are scanned automatically during installation. No secrets or personal examples added.

Version numbers here are product iterations, not published Python-package versions. The old GitHub Pages URL, if enabled, now only shows the skill install guide.
