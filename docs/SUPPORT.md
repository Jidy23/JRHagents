# Support JRHagents — voluntary appreciation

JRHagents remains free and MIT-licensed. Support is optional and never shown automatically.

- The only support control is the **heart icon next to the language switch in the top navigation**. It opens a compact accessible QRIS dialog.
- Prefer to contribute time? Read [CONTRIBUTING](../CONTRIBUTING.md) or submit a GitHub issue.
- The QRIS is supplied by the project operator. The **printed recipient is KOPDES NUSANTARA, not JRHagents**. Verify the recipient inside the payment app before authorizing any payment. Cancel if the name differs.
- The code image is a 456×456 1-bit losslessly optimized PNG. Its decoded payment payload matched the image supplied for this implementation in a local scan check.
- The site does not process money, inspect receipts, report donation totals, require nominal amounts, or offer exclusive features for money.
- The design is intentionally local-only HTML/CSS/JS, no analytics, external APIs, or tracking.
