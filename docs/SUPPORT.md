# Supporting JRHagents

JRHagents is free and open source (MIT). Support is always voluntary; no feature is locked, no amount is required, and no payment is needed to use the skill.

## Contribute without paying

Open a bug report, improve docs, suggest a small improvement, or submit a pull request. See [CONTRIBUTING.md](../CONTRIBUTING.md).

## Optional QRIS appreciation

The website's **Bantuan / Help** tab includes a **Support JRHagents** card and a QRIS dialog. The payment code was supplied by the project operator and re-encoded into a lightweight PNG. Its **decoded payload was checked to match the supplied image exactly** before inclusion.

**Recipient shown in the provided QRIS: KOPDES NUSANTARA.** It is not named JRHagents. Before paying, check the displayed recipient in your payment app, decide your own amount, and stop if it differs. This page does not process or verify payments. A transaction through this QRIS may be classified as a merchant payment by your provider; review fees/terms in the app.

For phone users, choose **Save QRIS image**, then use the gallery/import-QR option in a supported payment app if available. From another device, you can scan the code directly.

## Privacy and ethics

- No account, callback URL, webhooks or analytics are used for appreciation.
- No compulsory donation, target counter, emotional pressure, or repeated prompts.
- We never ask for a screenshot/receipt or claim payment succeeded.
- Contributions grant no special access or financial product.
- Github contributions and financial appreciation are separate choices.
- The support card is shown only on the Help tab or after visitors choose the footer link.
