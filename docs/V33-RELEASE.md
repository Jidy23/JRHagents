# JRHagents V33 — Nine-level upgrade

## Why this release exists
People were forced through long pages and a misleading terminal installation path even in chat-only AI. V33 makes **the actual outcome** available from an accessible compact four-tab interface.

| Level | Upgrade | Verifiable user-facing effect |
|---|---|---|
| V25 | Real audience routing | Chatbot / AI-coding choice changes the instructions |
| V26 | No-shell-first setup | ChatGPT, Claude web, Gemini web receive full copyable instructions without `npx` |
| V27 | Compact grid layout | Four tabs, bottom mobile nav, paginated capability grid |
| V28 | Accurate masked preview | Blur hides preview visually; clipboard copies the full public instructions |
| V29 | 66 scoped workflows | Every item has a title, task intent, expected deliverable, reference |
| V30 | Indonesian + English | Bilingual UI and bilingual catalog names/descriptions |
| V31 | Accessible navigation | Keyboard focus, clear pressed state, semantic roles, reduced-motion |
| V32 | Lightweight visual system | CSS-only dimensional artwork, no framework, CDN or 3D runtime |
| V33 | Testable release | Catalog generator, tests, real browser smoke, CI publication |

## The 66-workflow boundary
These are **workflow instructions** that adapt to host AI capabilities; they are not 66 integrations, API subscriptions or autonomous agents. The repo remains one canonical `SKILL.md` with 11 specialized references. Health is educational, finance is scenario-based, cybersecurity is defensive and permission-bound.

## Mobile onboarding
Mobile users see the app choice first; only after pressing “Lihat instruksi saya” does the copyable output appear. They do not need to scroll past both steps at once. Chat platforms default to zero-terminal instructions.

## Privacy and honesty
Blur is merely a visual effect: the same public instruction content can be read in the repository. No secrets, credentials, hidden paid services or remote model claims are involved. The website does not run AI. It provides real search/filter, copy/download, onboarding and help.
