SETELAH TERPASANG

Mulai dari perintah yang berguna.

Ini perintah JRHagents yang benar-benar tersedia di CLI, bukan contoh fitur AI yang belum dibuat.

01

Periksa komputer

Ketahui kondisi lingkungan dan proyek.

jrhagents doctor --project .
02

Audit proyek

Cari indikasi masalah dalam kode lokal.

jrhagents audit --project .
03

Buat rencana kerja

Ubah instruksi biasa menjadi langkah konkret.

jrhagents plan "rapikan tampilan"
04

Buat laporan

Susun hasil pemeriksaan yang bisa dibuka.

jrhagents report --project .

PERTANYAAN UMUM

Kalau masih bingung, mulai dari sini.

Tidak perlu langsung memasang semuanya. Coba audit browser, lalu pilih satu aplikasi AI yang biasa dipakai.

Laporkan kendala nyata ↗
Apakah website ini benar-benar bekerja?

Ya, audit browser membaca berkas yang kamu pilih dan memberi temuan statis beserta nomor baris. Tidak menjalankan AI, tidak mengunggah berkas, dan tidak menggantikan audit keamanan profesional.

Kenapa butuh Python untuk memasang Skill/MCP?

JRHagents memakai aplikasi kecil berbasis Python untuk menyiapkan file Skill, konfigurasi MCP, dan audit di komputermu. Website sendiri tetap bisa dipakai untuk audit cepat tanpa Python.

Apakah bisa dipasang tanpa masuk terminal?

Audit browser bisa. Untuk menjalankan CLI/MCP di komputer, kamu masih perlu Python dan terminal. Panduan interaktif menyediakan perintah sesuai Windows, macOS, dan Linux agar kamu tidak perlu menebak.

Apakah semua 26 kemampuan bisa dijalankan sendiri?

Belum. Sebagian adalah fungsi lokal, sebagian panduan untuk AI coding, dan sebagian inspirasi dari proyek open source lain. Label di bagian kemampuan menjelaskan status sebenarnya.

Apa yang harus dilakukan jika perintah gagal?

Cek Python versi 3.9+, pastikan internet tersedia ketika pemasangan, dan jalankan perintah dalam folder proyek yang sesuai. Untuk MCP, mulai ulang aplikasi AI setelah setup. Jika pengaturan lama berbeda, JRHagents tidak menimpanya.
