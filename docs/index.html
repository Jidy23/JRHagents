PERTANYAAN UMUM

Kalau masih bingung, mulai dari sini.

Tidak perlu langsung memasang semuanya. Coba audit browser, lalu pilih satu aplikasi AI yang biasa dipakai.

Laporkan kendala nyata ↗
Apakah website ini benar-benar bekerja?

Ya, audit browser membaca berkas yang kamu pilih dan memberi temuan statis beserta nomor baris. Tidak menjalankan AI, tidak mengunggah berkas, dan tidak menggantikan audit keamanan profesional.

Apakah memasang Skill harus menggunakan Python?

Tidak. Gunakan perintah npx skills add dari GitHub. Dibutuhkan Node.js dan AI coding yang kompatibel. Python 3.9+ hanya dibutuhkan untuk CLI/MCP lokal.

Apakah bisa tanpa mengunduh ZIP?

Bisa. Skill diambil langsung dari GitHub memakai installer skills. Plugin Claude Code dapat ditambahkan dari marketplace GitHub. MCP lokal masih memerlukan konfigurasi dan runtime Python. Website Audit Cepat tetap bisa dipakai tanpa instalasi.

Apakah semua 26 kemampuan bisa dijalankan sendiri?

Belum. Sebagian adalah fungsi lokal, sebagian panduan untuk AI coding, dan sebagian inspirasi dari proyek open source lain. Label di bagian kemampuan menjelaskan status sebenarnya.

Apa yang harus dilakukan jika perintah gagal?

Cek Python versi 3.9+, pastikan internet tersedia ketika pemasangan, dan jalankan perintah dalam folder proyek yang sesuai. Untuk MCP, mulai ulang aplikasi AI setelah setup. Jika pengaturan lama berbeda, JRHagents tidak menimpanya.
