Setup

Panduan instalasi interaktif.

Pilih tool dan sistem operasi. Perintah dibuat langsung di browser tanpa mengirim datamu ke server.

Python 3.9+

Pasang untuk Codex

Buka terminal di folder JRHagents yang sudah diekstrak, lalu jalankan:

python scripts/jrhagents.py install --client codex --project .

Installer tidak menimpa skill lama. Perintah harus dijalankan di komputer kamu, bukan di website ini. Jika terminal belum tersedia, minta AI coding membaca SKILL.md dari folder ini.
