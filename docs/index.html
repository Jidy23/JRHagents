Laporkan kendala ↗
JRHagents ini apa, sebenarnya?

Satu paket instruksi yang membantu AI mengerjakan tugas lebih sistematis dan memeriksa hasil. Bukan aplikasi AI baru atau model AI tambahan.

Apakah gratis dan perlu API key?

Kode Skill JRHagents gratis dengan lisensi MIT dan tidak memerlukan API key JRHagents. Aplikasi AI yang kamu gunakan mungkin membutuhkan akun atau langganan sendiri.

Bisa dipakai di ChatGPT atau Claude web?

Bisa menggunakan instruksi universal dengan cara ditempel ke percakapan atau pengaturan yang didukung. Itu bukan instalasi Skill native.

Kenapa instalasi tidak langsung dari website?

Website ini hanya panduan. Skill native dipasang oleh aplikasi/installer di komputermu. JRHagents tidak meminta akses perangkat atau menjalankan instalasi diam-diam lewat halaman.

Apakah semua AI di dunia kompatibel?

Tidak ada standar instalasi yang sama untuk semua AI. JRHagents mendukung format Agent Skills untuk AI yang kompatibel, dengan instruksi manual untuk chatbot lain. Hasil tetap tergantung kemampuan host.

Apa yang harus dilakukan jika Skill tidak terbaca?

Pastikan aplikasi dan versinya mendukung Agent Skills, periksa folder instalasi dari installer, lalu coba restart aplikasi. Lihat panduan instalasi untuk detail.
