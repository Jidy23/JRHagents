Instalasi

Pilih cara yang paling mudah.

Kamu tidak harus tahu apa itu MCP atau Plugin. JRHagents V22 adalah satu Agent Skill.

Pasang langsung dari GitHub

Memerlukan Node.js, internet, serta aplikasi AI coding yang mendukung Agent Skills.

npx skills add Jidy23/JRHagents --skill jrhagents

Perintah mengambil Skill dari GitHub. Tidak memasang API, model AI, atau MCP. Ikuti pilihan aplikasi yang muncul di terminal.

Panduan lengkap & pemecahan masalah ↗

Tanpa terminal: pakai instruksi manual

Untuk chatbot biasa, buka berkas instruksi ringkas lalu salin ke instruksi khusus atau percakapan. Cara ini tidak memasang skill native dan tidak menambah tool ke chatbot.

Buka instruksi siap tempel ↗

Jika AI kamu mendukung impor Skill sendiri, ikuti panduan resminya. Jangan menganggap semua AI memiliki sistem instalasi yang sama.
