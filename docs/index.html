05 / GOOD TO KNOW

Yang perlu kamu tahu.

Batasan dijelaskan sejak awal. Tidak ada tombol yang pura-pura memasang skill dari jarak jauh.

Apakah gratis dan open-source?+

Ya. Kode ini dirilis dengan lisensi MIT. Koneksi AI berbayar, jika dipilih pengguna di luar paket, mengikuti biaya provider masing-masing.

Apakah semua 26 kemampuan langsung bekerja?+

Tidak. Ada fungsi CLI nyata seperti audit, routing, diagnosis, rencana, laporan dan installer. Sebagian kemampuan lainnya adalah petunjuk kerja yang membutuhkan dukungan tool pada klien AI. Konektor pihak ketiga tidak disertakan.

Apakah harus memberikan API key?+

Tidak untuk dokumentasi dan utilitas lokal. Halaman ini tidak mengumpulkan API key, menggunakan analytics, atau menghubungi server aplikasi.

Bisa digunakan di ponsel?+

Halaman panduan ini responsif dan bisa dibaca dari ponsel. Untuk menjalankan CLI/MCP diperlukan Python 3.9+ pada komputer atau lingkungan kompatibel; mobile hanya untuk membaca panduan.

Apa beda audit dan verifikasi?+

Audit membaca konfigurasi dan berkas lokal secara heuristik. Verifikasi dapat mengevaluasi tes/build hanya bila pengguna menambahkan flag persetujuan. Tes tidak dijalankan diam-diam.
