Salin perintah berikut. Tutup dan buka lagi aplikasi AI coding setelah pemasangan.

PERTANYAAN UMUM

Masih ada yang mengganjal?

Ini jawaban singkat untuk pertanyaan yang paling sering muncul saat baru mulai.

Laporkan masalah di GitHub ↗
JRHagents gratis, atau harus langganan?

Source JRHagents menggunakan lisensi MIT dan bisa dipakai gratis. Jika kamu memakai model AI, layanan cloud, atau tool pihak ketiga, biayanya mengikuti layanan tersebut.

Harus bisa coding dulu?

Tidak harus untuk mengikuti panduan, tetapi pemasangan lokal memakai Python dan Terminal. Wizard di halaman ini akan memandu langkahnya.

Apa bedanya Skill, MCP, dan Plugin?

Skill adalah panduan yang dibaca AI coding; MCP adalah alat yang bisa dipanggil aplikasi AI kompatibel; Plugin adalah format paket untuk platform yang mendukungnya. Tidak semua aplikasi memakai ketiga format tersebut.

Apakah semua 26 kemampuan bisa langsung dijalankan?

Belum. JRHagents mencakup sejumlah fungsi CLI dan lima tool MCP read-only; kemampuan lain merupakan panduan untuk AI coding atau memerlukan integrasi eksternal. Periksa label status tiap kemampuan.

Apakah JRHagents bisa di Windows, Mac, dan Linux?

CLI Python dirancang untuk ketiganya. Pemasangan skill tergantung dukungan dan versi aplikasi AI coding; konfigurasi MCP mengikuti pengaturan setiap klien.

Bagaimana kalau instalasi gagal?

Pastikan Python 3.9+ sudah terpasang, jalankan pemasangan dari folder source hasil ekstrak, dan cek bahwa Terminal memakai lingkungan Python yang sama. Baca panduan teknis untuk rincian tiap platform.
