Privacy Policy

This policy covers the JRH agents skill package and the JRHagents documentation website at jidy23.github.io/JRHagents.

Information handled by JRH agents

JRH agents is a skills-only package. It contains instructions and supporting files; it does not operate an AI model, API, MCP server, account connector, or database. The project does not receive or store your prompts, files, or generated responses through a JRH agents backend.

Your conversation is processed by the AI service you choose, such as ChatGPT, under that service's own terms and privacy policy. JRH agents does not add access to your accounts or grant the host new tools or permissions.

Documentation website

The documentation website uses bundled HTML, CSS, JavaScript, and image files. The project does not add analytics, advertising trackers, or third-party API calls to the site. GitHub Pages hosts the site; GitHub may process routine hosting and security information under its own policies. The project does not receive GitHub's infrastructure logs.

Support messages

If you report an issue through GitHub Issues, the information you submit is handled by GitHub. Issues may be publicly visible. Do not include passwords, private keys, sensitive personal information, or private files in a public issue. For security reports, follow the instructions in the repository's SECURITY.md.

Optional appreciation

The website may show an optional QRIS appreciation code. JRH agents does not process payments, inspect receipts, or record whether someone paid. The QRIS recipient is shown in the support information; verify the recipient in your payment app before authorizing a transfer. Any payment app or payment provider handles that transaction under its own terms and privacy policy. A contribution is not required and does not unlock features.

Retention and choices

The project does not maintain a database of conversations or site profiles. The AI host, GitHub, and any payment provider apply their own retention and deletion controls to information they handle. You can choose not to use the website or submit a support issue.

Changes and contact

This policy may be updated when the package or website changes. For questions, use the JRH agents support page or open an issue in the repository.
