Bantuan & Dukungan

Butuh bantuan memasang atau memakai JRHagents? Mulai dari panduan di bawah. JRHagents adalah agent skill gratis dan sumber terbuka; fitur yang tersedia mengikuti aplikasi AI dan izin yang Anda gunakan.

Mulai menggunakan ↗Pilih platform AI dan ikuti panduan langkah demi langkah. Panduan pemasangan ↗Instruksi untuk chatbot biasa dan AI coding yang mendukung skills. Laporkan masalah ↗Buka GitHub Issue publik untuk bug, pertanyaan, atau masukan. Laporkan masalah keamanan ↗Ikuti petunjuk pelaporan keamanan, bukan issue publik untuk informasi rahasia.

Sebelum melaporkan masalah

  1. Periksa kompatibilitas platform dan metode instalasi yang sesuai.
  2. Catat aplikasi AI, versinya (jika diketahui), langkah pemicu, hasil aktual, dan hasil yang diharapkan.
  3. Sertakan teks kesalahan yang sudah dibersihkan dari data rahasia atau informasi pribadi.

Privasi: GitHub Issues dapat diakses publik. Jangan pernah membagikan kata sandi, API key, token, data akun, atau berkas pribadi.

Lingkup dukungan

Proyek menyediakan panduan penggunaan, dokumentasi, dan sarana pelaporan isu. Tidak ada jaminan waktu respons. JRHagents sendiri tidak menyediakan akses ke model AI tambahan, MCP server, atau otomasi latar belakang.

Support in English

JRHagents is a free, open-source workflow skill. For help, consult the installation guide, check platform compatibility, or open a GitHub issue. Do not post secrets or personal information publicly. For security issues, follow SECURITY.md.
