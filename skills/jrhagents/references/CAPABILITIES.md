# 26 capabilities — logical practices, not 26 bundled integrations

The first 10 are *ideas inspired by* public projects, not copied software, installed agents, licensed runtimes or verified live features. Users never need to install those projects to use the JRHagents guidance.

| 04 | Humanizer-style Writing | Produce natural, audience-aware language | writing |
| 05 | Onyx-style Knowledge Grounding | Ground claims in files already accessible through host tools | research |
| 06 | Impeccable-style UI Polish | Check alignment, interaction and component consistency | design |
