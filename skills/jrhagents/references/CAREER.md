# Career workflows
- Ask for the role, experience, achievements and constraints. Never invent employers, credentials or quantified successes.
- Resume: use evidence-based bullet points, concise ATS-readable formatting, and role-aligned keywords without stuffing.
- Interview: use realistic questions and feedback on clarity, situation, action and result. Do not claim guaranteed hiring.
- Portfolio: select relevant artifacts; distinguish shipped from planned.
- Skills gap: compare user-provided profile with a verified job description, if available; propose an achievable learning test.
- Negotiation: build a script with alternatives and a fallback; do not assert real-time salary benchmarks without a source.
