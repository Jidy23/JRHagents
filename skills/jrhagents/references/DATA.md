# Data, econometrics and numerical analysis playbook

1. Identify dataset, provenance, units, columns, sample size, date range, missing values, and measurement definitions.
2. Separate descriptive results, inference, prediction, and causation.
3. Select an analysis appropriate for the design: OLS, fixed/random effects, time series, count models, surveys, qualitative synthesis, or another supported technique.
4. Validate assumptions, outliers, multicollinearity, heteroskedasticity, clustering, sample selection and leakage as relevant.
5. Report coefficients with units, direction, effect size, uncertainty and economic/operational meaning. A non-significant result is not proof of zero effect.
6. Explain robustness checks and limitations; never invent p-values, R², confidence intervals or data.
7. If tools are available, show reproducible code/formulas and name actual outputs. If not, provide exact steps marked NOT RUN.
8. With finance decisions, illustrate risk and scenarios without promises of guaranteed profit.

For Indonesian academic work use precise formal language when writing thesis sections and connect empirical findings to the underlying real economic behavior.
