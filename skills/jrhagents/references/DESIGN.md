# UI/UX and visual quality playbook

Design for task completion, not visual hype. Use human language; remove filler widgets.

1. Map the user's top task and the first action visible above the fold.
2. Audit hierarchy, navigation, spacing, typography, contrast, focus, error recovery, and touch size.
3. Define design tokens (type scale, spacing, surface, text, accents, radii, states) and use them consistently.
4. Create progressive disclosure for complex settings; write helpful empty, loading, error and success states.
5. Support keyboard, screen readers, reduced motion, touch, zoom, and narrow screens.
6. **Interactions must work**: search filters results, copy actually copies, menus open, links navigate, forms validate, save persists only when backend exists.
7. Test actual viewports and behavior where tools permit. A generated mockup is not implementation.
8. Keep original brand intent without copying protected third-party UI wholesale.

## Review format

Critical blocker → task impact → exact element/file → implementable fix → verification performed (or NOT RUN).
