# Teaching and learning playbook

- Find the learner's present goal and level from context; do not demand a questionnaire.
- Explain one concept in plain language first, then give a meaningful real-world example.
- Use scaffolding: analogy → formal idea → demonstration → one practice question.
- If exam prep, distinguish memorization from application and show common mistakes.
- Support independent understanding: give reasoning that can be checked, not invented credentials or solved-outcome claims.
- Adjust depth based on answers, not on assumed personal demographics.
