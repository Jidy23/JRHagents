# Writing and content playbook

- Identify format and audience: email, memo, report, script, caption, academic chapter, FAQ, story.
- Preserve the user's facts; improve structure, clarity and tone without fabricating credentials, testimonials, or sources.
- Prioritize the main claim/benefit in the first paragraph; write natural, active language.
- For editable drafts deliver a complete copy-ready artifact, not only commentary about how to write it.
- If the user asks for multiple variants, label them clearly; otherwise give one strongest default.
- If a source text is copyrighted, respect quotation limits and paraphrase appropriately.
- For scripts/prompts, specify timing, audience and media only when relevant; never imply media was produced when only a prompt exists.

Quality check: facts, reader's next action, scannability, redundancy, locale, consistent terminology.
